# 🧠 Memory Card Game

## 📌 Description

Memory Card Game is a small interactive web game developed with HTML, CSS and Vanilla JavaScript.

The goal of the game is to find all the matching pairs of cards.

The cards are generated dynamically from a JavaScript array and shuffled at the beginning of the game and when restarting.

## ✨ Features

* 12 cards representing 6 pairs
* Dynamic card generation with JavaScript
* Random shuffle of the cards
* Card flip interaction
* Only two cards can be selected at a time
* Automatic comparison of selected cards
* Matching cards remain visible
* Non-matching cards are hidden again after a short delay
* Moves counter
* Found pairs counter
* Victory message when all pairs are found
* Restart button
* Responsive design for desktop and mobile

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Git & GitHub

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `memory-card-game` folder.
3. Open `index.html` in a web browser.
4. Start playing!

No backend or installation is required.
